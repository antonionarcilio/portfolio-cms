  Plataformas institucionais desenvolvidas com foco em performance, SEO técnico, acessibilidade, integrações com ferramentas de marketing e suporte multilíngue (PT-BR e EN).

  Atuei no desenvolvimento e manutenção do website institucional do Escallo, implementando funcionalidades customizadas e integrações com serviços externos como RD Station. Desenvolvi fluxos de conversão de leads com validação de segurança utilizando Cloudflare Turnstile antes do envio dos dados à API do RD Station, além de integrações personalizadas no Elementor para mapeamento dinâmico de campos customizados cadastrados no RD Station por meio de Dynamic Tags. Também atuei na implementação de rastreamento de eventos (gtag), otimizações de performance, responsividade, Core Web Vitals e melhorias voltadas à experiência de navegação do usuário.

what_i_built: |-
  Atuei na manutenção e evolução do site institucional, trabalhando tanto na versão anterior quanto na atual. Em ambas, participei de atualizações de layout, melhorias de interface, responsividade e implementação de funcionalidades customizadas.

  Também fui responsável pela integração dos formulários do site com a API do RD Station, permitindo o envio dos dados submetidos pelos usuários diretamente para a plataforma. Para isso, implementei o gerenciamento do processo de submissão no próprio site, incluindo a validação dos dados antes do envio.

  Além disso, implementei a validação de segurança dos formulários utilizando Cloudflare Turnstile e atuei na implementação de rastreamento de eventos com gtag.

  Também trabalhei em melhorias relacionadas à performance, acessibilidade, responsividade e experiência de navegação, além da manutenção e atualização das versões PT-BR e EN do site.
challenge: |-
  Um dos principais desafios foi a integração dos formulários com o RD Station. A plataforma disponibilizava um plugin/script para monitorar os formulários do site e identificar eventos como a submissão, porém esse mecanismo não funcionava corretamente quando os formulários eram utilizados dentro de modais.

  Como alternativa, optei por assumir o controle do fluxo de submissão diretamente na aplicação. A solução passou a gerenciar manualmente a submissão dos formulários, realizando as validações necessárias e, após a confirmação dos dados, enviando as informações diretamente para a API do RD Station.

  Também enfrentei desafios relacionados à performance e aos Core Web Vitals, trabalhando na identificação de pontos que impactavam o carregamento e a experiência de interação com as páginas. Foi necessário analisar o comportamento da aplicação e realizar ajustes para melhorar o desempenho e a responsividade do site, considerando os diferentes dispositivos e condições de acesso.

  Outro desafio esteve relacionado à segurança dos formulários, integrando o Cloudflare Turnstile ao fluxo de submissão para validar a interação do usuário antes do envio dos dados.

  Além disso, a evolução das diferentes versões do site exigiu conciliar mudanças de layout, responsividade, acessibilidade e performance, mantendo uma experiência consistente enquanto novas funcionalidades eram incorporadas.
result: |-
  O trabalho contribuiu para a evolução contínua do site institucional, mantendo uma experiência responsiva, acessível e consistente entre diferentes dispositivos e idiomas.

  A integração direta com a API do RD Station proporcionou maior controle sobre o processo de submissão dos formulários, permitindo que os fluxos de conversão funcionassem de forma independente do mecanismo de monitoramento disponibilizado pela plataforma.

  As melhorias de interface e performance também contribuíram para uma experiência de navegação mais consistente ao longo das diferentes versões do site.
